# 产品首次接入单选与预注册入口

## 正式契约

产品创建、编辑、详情统一使用单值 `authMode`，不再发送或读取 `authModes`。

| 页面选择 | authMode | bootstrapMode | 凭证页面主要操作 |
| --- | --- | --- | --- |
| 设备密钥 | DEVICE_SECRET | null | 制造批次、领取单、导出、设备凭证管理 |
| 预注册 | PRODUCT_SECRET | STRICT | 产品密钥、预注册名单、设备凭证管理 |
| 动态注册 | PRODUCT_SECRET | OPEN | 产品密钥、设备凭证管理 |
| 自定义认证 | CUSTOM | null | 保留提供方配置，需填写 customAuthProviderId |

首次接入选项互斥，切换选项同时更新注册模式并清除不适用的提供方字段。设备密钥路线不显示“注册模式未配置”。创建和编辑共用同一个单选组件。

只有已发布的 PRODUCT_SECRET + STRICT 产品可以添加预注册 UUID。OPEN 不展示预注册名单入口，也不请求预注册列表；DEVICE_SECRET 不使用预注册名单生成制造批次。产品密钥路线默认展示预注册名单或设备凭证，不显示无法使用的制造、领取单和导出标签。

预注册与动态注册取得 DeviceSecret 后，都按已有设备凭证流程工作。不能把首次接入路线误解为运行时不使用设备密钥。
