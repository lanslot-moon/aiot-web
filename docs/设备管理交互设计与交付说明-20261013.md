# 设备管理交互设计与交付说明

## 范围与依据

以 aiot-web 的 main 分支为基础，只新增设备管理界面、设备请求契约和设备交互组件。产品、策略、登录及共享认证逻辑不变；现有工作区导航仅移除设备入口的“未发布”标记。接口依据 aiot-cloud 当前 Manager 的六个北向 API 接口及 Request、VO 定义。

## 页面与任务

入口沿用项目左侧“设备”，页内分为设备列表与静态分组，不增加第二套导航或视觉框架。

| 页面 | 操作与反馈 |
| --- | --- |
| 设备列表 | 名称或昵称前缀查询，设备 ID、产品 ID、硬件标识精确查询；按生命周期、实体/虚拟、节点类型筛选；游标上一页/下一页与手动刷新 |
| 设备详情 | 查看不可变身份、产品、认证摘要和时间；编辑昵称和说明；完整替换资料时保留现有图标引用 |
| 管理状态 | 待激活、已激活、已停用、删除中；启停前说明影响，可填写操作说明；停用后启用由后端依据激活事实恢复状态 |
| 删除 | 输入完整设备名称确认；删除中禁止资料和标签编辑；失败后重新读取事实，允许继续删除同一设备 |
| 虚拟设备 | 选择已发布产品或输入产品 ID，名称可省略由后端生成；只创建待激活档案，不创建凭证、绑定策略或启动模拟 |
| 标签 | 读取完整集合，按键设置与移除，允许空值；不混入产品标签或成员标签 |
| 硬件资料 | 可信登记与设备自报分别呈现；显示序列号、硬件版本、来源、接收时间及网卡；按需请求 |
| 静态组 | 从根组逐层进入子组；创建根组/子组、编辑资料、组标签；父组固定不能移动 |
| 直接成员 | 查看指定组直接成员，查看设备直接所属组；单项移出不删除设备；从分组进入设备详情后可返回该组 |
| 批量成员 | 添加候选由 N25 排除已有直接成员；支持跨页选择，单批最多 200 项；批量移出只影响当前组直接关系 |

不将 ACTIVE 解释为在线，不展示 Manager 没有返回的实时连接状态。实体设备经预配登记，不提供虚构的手工实体登记或手工激活入口。

## 请求与异常约定

- 请求沿用现有同源网关与会话处理，项目路径和 X-Project-Id 使用真实项目 ID。浏览器不生成 tenantId，不发送可信用户或租户头。
- 读取按项目和登录会话隔离缓存；等待授权时保持加载，不在切换项目时展示原项目内容。
- 查询失败保留错误与手动重试，不将失败视为空集合；请求失败时不继续显示加载动画。已获得的数据在后台刷新失败时保留。
- 所有分页遵循 items、nextCursor、hasMore，不估算总量，不将游标替换为数字总页数。筛选改变后重置游标。
- 写操作由发起按钮显示提交状态，阻止重复提交；所有成功反馈等待后端确认。
- 虚拟创建在网络、服务异常或未知响应后要求先核对列表，避免超过接口短窗再次提交创建另一台设备。
- 成员批量响应逐项展示 CHANGED、UNCHANGED、FAILED、UNKNOWN。部分失败不覆盖成功项；无响应时停止直接重提，先重新读取关系核对。
- 操作入口沿用 IAM 的 device:view、device:create、device:update、device:delete；静态组未新增权限码。最终权限校验由网关和服务端负责。

## 状态覆盖

| 状态 | 实现 |
| --- | --- |
| loading | 列表、按需详情和候选产品的局部加载；提交按钮文案 |
| empty | 仅在成功读取空集合后显示；设备筛选为空与首次无设备分别说明 |
| error | 复用 ErrorNotice；服务故障使用中性状态，权限及业务错误清楚显示 |
| disabled | 权限、删除中、重复提交、选择达到 200 项、分页边界 |
| focus | 复用 Base UI 按钮、标签页、选择器、对话框；输入带标签或 aria-label |
| selected | 当前页签、筛选、成员复选与跨页选择数量 |
| submitting | 写操作防重入，发送期间不能关闭提交对话框 |
| success | 服务端确认后关闭编辑、刷新事实或打开创建结果 |
| unknown | 虚拟创建与成员批量异常提供先核对再操作的指引 |

## 交付验证与限制

- Ran：TypeScript 检查与生产构建（npm run build）、全项目 lint（npm run lint）、git diff --check。
- Manual：使用已有本地 Chrome 会话打开设备页，浏览器可访问性树呈现设备页签、筛选、创建入口及错误反馈。当前设备查询实际返回 HTTP 403，显示没有访问权限。
- Skipped：功能测试、自动 UI 测试及新增测试类，遵循用户要求“只有明确要求测试才运行或新增测试”。技能自带 state coverage/visual smoke 测试脚本同样未运行。
- Skipped：完整截图视觉验收及移动端验收；当前原生浏览器截图返回白色图像，不能作为布局验收证据。
- Planned：在设备路由授权可用后，使用真实 Manager 数据完成列表、详情和写操作联调；本次没有执行设备创建、启停、删除或成员写入，也未改动 IAM、策略、网关配置或后端服务。

当前 HTTP 403 不足以判断是网关 API 资源登记还是账号授权问题，不能宣称真实设备管理链路已经验收。构建通过只证明前端可编译，不证明远端接口已开放。
