# 凭证生命周期交互与演示数据

## 交互决定

沿用产品功能导航，不隐藏“凭证与量产”入口，避免功能位置随生命周期变化。

- 草稿：仅显示发布引导及“返回产品，完成发布”，不请求凭证列表，不显示创建表单。
- 已发布：按接入路线开放操作；设备密钥使用量产批次，预注册维护 UUID 名单，动态注册不提供名单入口。
- 已废弃：保留历史列表、批次详情及领取单详情；显示只读说明，禁止签发、轮换、冻结、解冻、吊销、制造项作废、名单变更、导出和下载密钥。
- 已停用：同样只读，并说明重新启用后才能继续操作。

操作按钮和弹窗同时受生命周期约束。创建资格由后端产品服务检查 PUBLISHED；本次不修改认证与激活规则。
