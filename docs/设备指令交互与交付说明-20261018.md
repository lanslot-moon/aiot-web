# 设备指令模块

入口：项目 → 设备管理 → 设备详情 → 设备指令。只替换已有占位页签；产品、物模型编辑、凭证及其他页面未修改。

## 交互设计

使用 senior-ui-ux-orchestrator、webapp-ui-skill、ui-ux-pro-max 和项目 shadcn-dashboard-free 技能。沿用现有主题和设备页面的紧凑布局，不采用检索工具建议的营销首页或独立深色主题。

参考官方模式：
- [阿里云在线调试](https://help.aliyun.com/zh/iot/user-guide/online-debugging)：选择服务、填写 JSON、发送指令、查看日志。
- [涂鸦设备控制](https://developer.tuya.com/cn/docs/cloud/device-control?id=K95zu01ksols7)：按设备支持的指令集进行控制。

流程：选择属性设置或动作调用 → 从已发布物模型选功能 → 可视化填写参数（高级模式可编辑 JSON） → 核对设备、参数、发送期限 → 确认下发 → 刷新记录 → 查看投递状态与设备回复。属性可一次填写多个键。参数 JSON 对象、属性数量、UTF-8 大小、动作编码及期限在本地检查；完整物模型规则以服务端校验为准。

下发中锁定提交并禁用编辑。每次新控制生成 clientToken；不自动重发。结果不明时提醒先核对记录。界面不把设备激活状态当作实时在线，也不把 Broker 接收当作设备执行成功。记录为手动刷新，不声称实时推送。

## 实际接口

读取本地 aiot-cloud/aiot-command 当前 API、请求和 VO，以及 IAM 接口资源 SQL 后对接：
- POST /api/v1/commands/{deviceId}/properties/issue
- POST /api/v1/commands/{deviceId}/actions
- GET /api/v1/commands/{deviceId}/commands
- GET /api/v1/products/{productId}/model/published（只读）

复用登录客户端、X-Project-Id；查看记录为 device:view，下发为 device:command，模型读取为 product:view。未增授权限、未修改共享客户端。单设备下发响应为 Boolean，不伪造 requestId。历史分页沿用服务端游标，默认最近 24 小时。

## 可视化默认模式修订

默认显示可视化表单，JSON 仅在“高级 · JSON”中显示。可写属性逐项勾选，未勾选的不下发；动作必填参数直接显示，可选参数勾选后发送。支持布尔开关、数值范围、整数、文本、类型保持的枚举、嵌套对象、数组增删。输入值在字段失焦后提示错误，提交时检查必填和范围。确认框默认展示可读名称与目标值。

两种编辑模式共享参数内容。高级模式存在非法 JSON、未知键、类型不可表示或复杂 Schema 参数时阻止切回，保留全部文本并解释原因。复杂参数可继续通过高级模式提交，完整 Schema 校验仍由服务端负责。没有物模型读取权限时不会伪造表单。

新增验证（Ran）：类型与数值边界断言；浏览器验证默认表单、属性包含、false 与数值在模式切换后保留、未知键转换拦截、枚举下拉、可读确认框、动作必填文本和数组添加。375px 下页面宽度与视口均为375。浏览器采用隔离演示，未向真实设备下发。

## 公共组件复用与视觉整理

视觉：统一32px控件，数值与单位组合、公共滑块精确输入、已调整行轻度高亮、图标撤销提示，保留紧凑布局。公共Slider旧data-horizontal样式与当前data-orientation属性不匹配，本模块通过组合className限定轨道尺寸，没有修改全局组件。

Ran：Lint、TypeScript和生产构建；浏览器公共下拉弹层与选择，滑块ArrowRight将24同步为24.1，JSON保留COOL/number/boolean类型，服务及可选参数Select，ScrollArea实际viewport高468内容高849，375px内容宽等于视口宽。截图为隔离演示数据，未下发真实指令，临时演示已移除。
