# 设备模拟交互设计

## 自动上报多规则与移除操作

自动上报不是模拟运行的必选项。设置页按定时规则逐条展示上报间隔、属性和事件，每条提供修改、移除；底部提供添加规则，多条时另提供移除全部自动上报。保持后端最多 128 条行为规则的约束，达到上限时说明原因。

规则头部使用标题区与操作区两列，上报间隔和数量在同一行展示，规则标识通过头部悬停提示查看，不单独占行。属性和事件共用紧凑的两列信息网格，名称与编码分行，取值方式与说明分行并左对齐，长文本只在所属列内换行。操作按钮保持稳定宽度，底部动作在窄屏分行并保持主要操作右对齐；不使用内容长度决定字段起点。

新增或编辑只替换本次选定的规则，合并保留其他行为规则、参数、脚本及初始属性。表单能够表达的单条属性规则使用表单，自定义条件或动作继续使用 JSON／脚本编辑，不能静默丢弃不能表达的内容。移除前确认范围，仍有静态 schedule 引用时先报出依赖规则，不发布无效模板。移除最后一条行为后使用不自动触发的 idle 规则，满足后端模板非空约束；页面显示尚未设置自动上报，仍能开启模拟、响应指令和单次上报。

操作沿用停止模拟后修改配置的边界，状态未确认、无权限、读取失败或提交期间禁用写入。从完整配置派生独立模板版本，仅更新当前实例绑定，保留原模板和其他实例。移除采用固定操作草稿及标识；失败后可手动重试。绑定写入结果未知时先读取当前绑定，已经应用则确认成功，修订冲突时拒绝覆盖；取消不回滚已经发布的版本，不自动重发写请求。

本次仅做前端实现与静态检查，不执行真实设备启停、模板发布、删除或 MQTT 联调；运行环境需与既有 API 契约一起验收。

采用 senior-ui-ux-orchestrator → webapp-ui-skill，结合项目 shadcn-dashboard-free 约定。先核对本地 Simulator 的 API、请求模型和运行边界，再实现前端。

## 用户目标与主流程

用户在虚拟设备详情内完成：选择行为模板 → 配置/预演 → 固定版本绑定 → 启动 → 查看会话与设备上报 → 停止。沿用设备详情导航，无需复制设备 ID、输入 Broker 或接触密钥。

首次进入：读取设备现有绑定；未配置时解释下一步。可以复用同产品模板的已发布版本，也可以创建模板并通过可视化属性生成器编排周期上报。新模板先保存名称，再预演和发布行为版本。发布不自动启动；绑定也不自动启动。

再次进入：优先呈现运行控制。期望状态、活动会话引用、持久化运行记录分别展示；不能把 RUNNING 期望状态当成在线事实。失败展示后端失败码并提供刷新/重新启动入口，不自动重试启动。

## UI 结构

- 页首：设备模拟说明、手动刷新。
- 未绑定：三步说明与模板配置入口。
- 已绑定：运行摘要、启动/停止、配置与运行记录两个页签。
- 配置：模板、固定版本、参数覆盖与初始属性覆盖；运行占用期间只读。
- 模板编辑：名称、上报周期、属性列表（固定值、随机、线性、正弦），高级行为 JSON 用于完整规则；行为预演结果与发布操作放在同一工作区。
- 运行历史：会话状态、启动/结束时间、版本、失败码；游标分页，不逐条查会话详情。
- 桌面配置分栏，移动端上下排列；长 ID 折行、表格局部滚动，按钮文字保持完整。

## 状态与交互约束

| 状态 | 反馈/可用操作 |
| --- | --- |
| 加载 | Loading，查询完成前不能新建绑定 |
| 空 | 明确尚未配置并提供模板入口 |
| 失败/无权限/路由未开放 | 原因与重试，保留编辑内容，不回退样例 |
| 提交 | 按钮忙碌且防重复；写入失败不自动重放 |
| 已预演 | 展示预计属性变化和效果，注明未发送消息 |
| 编辑预演后的配置 | 立即使预演结果过期，重新预演才能发布 |
| 已发布 | 不覆盖既有版本；可选择新版本重新绑定 |
| 活动会话 | 禁止改绑；可停止、刷新、查看运行记录 |
| 停用/解绑设备 | 禁止新建绑定或启动，仍可查询与停止已有模拟 |
| 实体设备 | 说明仅支持独立虚拟设备 |

## API 与验证边界

使用现有认证网关 `/api/v1/simulation/*`，带当前项目上下文，服务端执行最终鉴权。不发送可信租户身份头，不直连内部服务。只实现当前契约，无历史兼容。

后端列表目前只接受 cursor/pageSize，不支持 deviceId/productId 过滤：目录分页读取后在内存匹配，禁止逐行详情查询。对自动目录扫描设置上限，超过或游标异常时明确报错，不能视为不存在。版本详情只按用户当前选择读取。会话列表是升序分页，未读到活动会话时仅显示占用引用，不推断运行状态。

真实网关路由与 IAM 模拟权限登记尚未在本地部署配置中找到，需实际环境验证。前端不伪造成功，也不把隔离测试数据当作真实 MQTT 联调。
